Guia de Migração do Pangram 4

O Pangram 4 já está disponível na nossa API.

Devido a algumas atualizações relacionadas com a faturação, o Pangram 3.3.2 continua a ser a versão predefinida e permanecerá ativo até 30 de setembro de 2026.

Este guia aborda tudo o que precisa de saber sobre a migração para o Pangram 4.

Quais são as novidades do Pangram 4?

O Pangram 4 apresenta um modelo de deteção mais preciso, a deteção de humanização por segmento e um conjunto simplificado de rótulos de classificação. Consulte a ficha do modelo Pangram 4 para obter mais informações!

A estrutura geral da resposta mantém-se semelhante, pelo que a maioria das integrações deverá exigir apenas algumas alterações:

  • Solicitar o Pangram 4 explicitamente utilizando modelo: «pangram-4»
  • Atualizar para a versão 1.0.0 do SDK do Python
  • Apoie as novas etiquetas para janelas do Pangram 4
  • Opcionalmente, utilize os novos campos de humanização
  • Contabilizar o medidor de faturação da API atualizado

O Pangram 4 também regressa:

{
  "version": "4.0"
}

Devo migrar?

SIM, se:

  • Quer começar a utilizar o Pangram 4 antes de este se tornar a predefinição?
  • Utilize etiquetas de janela na sua aplicação ou nos seus fluxos de trabalho de produção
  • Quer ter acesso aos novos campos de humanização?
  • Precisa de tempo para testar a sua integração antes de 30 de setembro
  • Quer avaliar o modelo de faturação atualizado utilizando os seus volumes de pedidos habituais?

AINDA NÃO, se:

  • Preciso de mais tempo para validar o Pangram 4 num ambiente de teste
  • Depende das cadeias de caracteres exatas da etiqueta do Pangram 3.3.2 e ainda não atualizou a sua integração
  • É necessário analisar como a faturação por cada 100 palavras irá afetar a sua utilização

O Pangram 3.3.2 continua a ser a versão predefinida e permanecerá ativo até 30 de setembro de 2026.

Migração da API REST

Para quem utiliza a API REST, envie um PUBLICAÇÃO enviar para:

https://text.external-api.pangram.com/task

O corpo da solicitação deve agora incluir:

{
  "text": "...",
  "model": "pangram-4"
}

Uma vez que o Pangram 3.3.2 continua a ser a opção predefinida durante o período de transição, é necessário solicitar explicitamente o Pangram 4.

Exemplo de pedido

curl --request POST \
  --url https://text.external-api.pangram.com/task \
  --header "Content-Type: application/json" \
  --header "x-api-key: YOUR_API_KEY" \
  --data '{
    "text": "Your text goes here.",
    "model": "pangram-4"
  }'

Migração do SDK do Python

Para quem utiliza o SDK do Python, atualize para a versão 1.0:

pip instalar --upgrade pangram-sdk==1.0.0

Em seguida, solicite explicitamente o Pangram 4:

de pangrama importar Pangram

client = Pangram()

resultado = cliente.prever(
    texto,
    modelo="pangram-4",
)

Tal como acontece com a API REST, o Pangram 4 deve ser selecionado explicitamente durante o período de transição.

Alterações no esquema de resposta

A estrutura geral das respostas mantém-se familiar, com duas adições a cada Pangram 4 windows[] item:

CampoTipoDescrição
is_humanizedBooleanoIndica se a janela foi identificada como humanizada
humanizer_scoreNúmero de 0 a 1Pontuação de humanização para a janela

O Pangram 4 também regressa:

{
  "version": "4.0"
}

Migração de etiquetas de janela

A única alteração que poderá causar problemas de compatibilidade é o facto de os rótulos das janelas do Pangram 4 serem agora:

  • Gerado por IA
  • Com assistência de IA
  • Escrito por um ser humano

Com assistência de IA substitui o anterior Com um leve apoio da IA e Com assistência moderada da IA etiquetas.

Pangrama anterior 3.3.2 EtiquetaEtiqueta Pangram 4
Com um leve apoio da IACom assistência de IA
Com assistência moderada da IACom assistência de IA

Se a sua integração se ramificar com base em cadeias de caracteres exatas, atualize-a antes da migração.

Por exemplo, código que anteriormente tratava as duas etiquetas assistidas por IA separadamente:

if window["label"] in {
    "Lightly AI-Assisted",
    "Moderately AI-Assisted",
}:
    handle_ai_assisted(window)

Deve ser atualizado para:

se a janela["label"] == "Assistido por IA":
    handle_ai_assisted(janela)

Um gestor de etiquetas Pangram 4 completo poderia ter o seguinte aspeto:

rótulo = janela["rótulo"]

se rótulo == "Gerado por IA":
    handle_ai_generated(janela)
elif label == "Assistido por IA":
    handle_ai_assisted(janela)
elif label == "Escrito por humanos":
    handle_human_written(janela)
else:
    handle_unknown_label(janela)

Recomendamos manter uma opção alternativa para «etiqueta desconhecida», em vez de partir do princípio de que a API irá sempre devolver uma das cadeias de caracteres atualmente documentadas.

Guia de migração de campos

A maioria dos campos de resposta do Pangram 3.3.2 não requer alterações na transição para o Pangram 4.

Pangram 3.3.2 CampoCampo Pangram 4Status
windows[].labelwindows[].labelOs valores foram alterados
windows[].confiançawindows[].confiançaContinua a ser familiar
windows[].ai_assistance_scorewindows[].ai_assistance_scoreContinua a ser familiar
—windows[].is_humanizedNovo
—windows[].humanizer_scoreNovo
—versãoDevoluções "4.0"

A principal preocupação em termos de compatibilidade é windows[].label. As duas categorias anteriores assistidas por IA foram consolidadas numa única Com assistência de IA rótulo.

Alterações na faturação

Uma última nota: estamos a atualizar a forma como faturamos a nossa API.

Estamos a melhorar a granularidade do nosso contador de utilização. As solicitações passarão a ser cobradas por cada 100 palavras , em vez de por cada 1 000 palavras. Isto será vantajoso para muitos de vós.

Mas avisamos desde já: o Pangram 4 é um modelo maior e com mais funcionalidades e, por isso, tivemos de aumentar o preço.

Consulte a página de preços para obter as informações mais recentes sobre preços!

Antes de transferir todo o tráfego de produção para o Pangram 4, analise o modelo de faturação atualizado em função do comprimento e do volume típicos dos pedidos da sua aplicação.

Processo de migração recomendado

1. Atualize o seu cliente

Os utilizadores da API REST podem continuar a utilizar o ponto de extremidade de tarefas existente.

Os utilizadores do SDK do Python devem instalar a versão 1.0.0:

pip instalar --upgrade pangram-sdk==1.0.0

2. Solicitar explicitamente o Pangram 4

Adicione o parâmetro do modelo a cada pedido:

{
  "model": "pangram-4"
}

3. Atualizar as comparações exatas de etiquetas

Substituir as verificações de:

Com assistência ligeira da IA
Com assistência moderada da IA

Com:

Com assistência de IA

Verifique também se a sua integração suporta exatamente as quatro etiquetas do Pangram:

Gerado por IA
Com a ajuda da IA
Escrito por humanos

4. Apoiar os novos setores

Atualizar os tipos de resposta, os esquemas de validação, os modelos de base de dados e os fluxos de análise para dar suporte a:

windows[].is_humanized
windows[].humanizer_score
versão

Os novos campos da janela podem ser considerados opcionais numa fase inicial, caso a sua aplicação ainda não utilize a análise de humanização.

5. Rever os pressupostos de faturação

A partir de agora, os pedidos serão cobrados por cada 100 palavras, em vez de por cada 1 000 palavras.

Teste o efeito utilizando tráfego de produção representativo.

Lista de verificação para a migração

  • Atualizar o SDK do Python para pangram-sdk==1.0.0, se for o caso
  • Adicionar modelo: «pangram-4» para pedidos de API
  • Eliminar dependências de Com um leve apoio da IA
  • Eliminar dependências de Com assistência moderada da IA
  • Suporte Com assistência de IA
  • Adicionar suporte para windows[].is_humanized
  • Adicionar suporte para windows[].humanizer_score
  • Verifique se a versão da resposta é "4.0"
  • Analise o novo sistema de faturação por cada 100 palavras
  • Teste a migração antes de 30 de setembro de 2026

Alguma dúvida?

Estamos ansiosos por ver todos a utilizarem o Pangram 4. Não hesitem em contactar-nos se tiverem algum problema. Estaremos ainda mais disponíveis nos próximos dias!

Para obter apoio na migração, contacte support@pangram.com.
