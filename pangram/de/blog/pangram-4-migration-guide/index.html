Pangram 4 – Migrationshandbuch

Pangram 4 ist nun in unserer API verfügbar.

Aufgrund einiger Änderungen im Abrechnungssystem ist Pangram 3.3.2 weiterhin die Standardversion und wird bis zum 30. September 2026 verfügbar bleiben.

Dieser Leitfaden enthält alles, was Sie über die Migration auf Pangram 4 wissen müssen.

Was ist neu in Pangram 4?

Pangram 4 bietet ein präziseres Erkennungsmodell, eine segmentbezogene Erkennung von Humanisierungen sowie einen vereinfachten Satz von Klassifizierungsbezeichnungen. Weitere Informationen finden Sie auf der Pangram-4-Modellkarte!

Die allgemeine Struktur der Antworten bleibt unverändert, sodass die meisten Integrationen nur wenige Änderungen erfordern sollten:

  • Fordern Sie „Pangram 4“ ausdrücklich an, indem Sie Folgendes verwenden: Modell: „pangram-4“
  • Auf Version aktualisieren 1.0.0 des Python-SDK
  • Unterstützen Sie die neuen Pangram 4-Fensteretiketten
  • Verwenden Sie optional die neuen Humanisierungsfelder
  • Konto für den aktualisierten API-Abrechnungszähler

Auch Pangram 4 kehrt zurück:

{
  "version": "4.0"
}

Sollte ich umziehen?

JA, wenn Sie:

  • Möchten Sie Pangram 4 schon nutzen, bevor es zur Standardeinstellung wird?
  • Verwenden Sie Fensterbeschriftungen in Ihren Anwendungs- oder Produktionsabläufen
  • Möchten Sie Zugriff auf die neuen Humanisierungsfelder erhalten?
  • Sie benötigen Zeit, um Ihre Integration vor dem 30. September zu testen
  • Möchten Sie das aktualisierte Abrechnungsmodell anhand Ihrer üblichen Anfragemengen testen?

NOCH NICHT, wenn du:

  • Ich benötige mehr Zeit, um Pangram 4 in einer Staging-Umgebung zu validieren.
  • Sie sind auf die genauen Pangram-3.3.2-Bezeichnungszeichenfolgen angewiesen und haben Ihre Integration noch nicht aktualisiert.
  • Sie sollten prüfen, wie sich die Abrechnung pro 100 Wörter auf Ihre Nutzung auswirkt

Pangram 3.3.2 ist weiterhin die Standardversion und wird bis zum 30. September 2026 verfügbar bleiben.

Migration der REST-API

Für diejenigen, die die REST-API nutzen, senden Sie eine BEITRAG Anfrage an:

https://text.external-api.pangram.com/task

Der Request-Body sollte nun Folgendes enthalten:

{
  "text": "...",
  "model": "pangram-4"
}

Da Pangram 3.3.2 während der Übergangsphase weiterhin als Standardversion gilt, müssen Sie Pangram 4 ausdrücklich anfordern.

Beispielanfrage

curl --request POST \
  --url https://text.external-api.pangram.com/task \
  --header "Content-Type: application/json" \
  --header "x-api-key: YOUR_API_KEY" \
  --data '{
    "text": "Your text goes here.",
    "model": "pangram-4"
  }'

Migration des Python-SDK

Wenn Sie das Python-SDK verwenden, führen Sie bitte ein Update auf Version 1.0 durch:

pip install --upgrade pangram-sdk==1.0.0

Fordern Sie dann Pangram 4 ausdrücklich an:

aus Pangram import Pangram

Client = Pangram()

Ergebnis = client.vorhersage(
    text,
    Modell=„pangram-4“,
)

Wie bei der REST-API muss Pangram 4 während der Übergangsphase ausdrücklich ausgewählt werden.

Änderungen am Antwortschema

Die allgemeine Antwortstruktur bleibt unverändert, wobei jedes Pangram 4 um zwei Elemente ergänzt wird. windows[] Punkt:

FeldTypBeschreibung
is_humanizedBooleschGibt an, ob das Fenster als humanisiert identifiziert wurde
humanizer_scoreZahl von 0 bis 1Humanisierungswert für das Fenster

Auch Pangram 4 kehrt zurück:

{
  "version": "4.0"
}

Migration von Fensteretiketten

Die einzige Änderung, die möglicherweise zu Kompatibilitätsproblemen führen könnte, ist, dass die Fensterbezeichnungen in Pangram 4 nun wie folgt lauten:

  • Von KI generiert
  • KI-gestützt
  • Von Menschen verfasst

KI-gestützt ersetzt die vorherige Leicht KI-gestützt und In moderatem Umfang KI-gestützt Etiketten.

Vorheriges Pangram 3.3.2 – BezeichnungPangram 4-Etikett
Leicht KI-gestütztKI-gestützt
In moderatem Umfang KI-gestütztKI-gestützt

Falls Ihre Integration anhand exakter Label-Zeichenfolgen verzweigt, aktualisieren Sie diese vor der Migration.

Beispielsweise Code, der die beiden KI-gestützten Bezeichnungen zuvor getrennt behandelt hat:

if window["label"] in {
    "Lightly AI-Assisted",
    "Moderately AI-Assisted",
}:
    handle_ai_assisted(window)

Sollte wie folgt aktualisiert werden:

wenn Fenster["Bezeichnung"] == „KI-gestützt“:
    handle_ai_assisted(Fenster)

Ein vollständiger Pangram-4-Label-Handler könnte wie folgt aussehen:

Bezeichnung = Fenster[„Bezeichnung“]

wenn Bezeichnung == "KI-generiert":
    handle_ai_generated(Fenster)
elif label == „KI-gestützt“:
    handle_ai_assisted(Fenster)
elif label == „Von Menschen verfasst“:
    handle_human_written(Fenster)
sonst:
    handle_unknown_label(Fenster)

Wir empfehlen, einen Fallback für unbekannte Bezeichnungen beizubehalten, anstatt davon auszugehen, dass die API immer eine der derzeit dokumentierten Zeichenfolgen zurückgibt.

Leitfaden zur Feldmigration

Die meisten Antwortfelder von Pangram 3.3.2 erfordern bei der Umstellung auf Pangram 4 keine Änderungen.

Pangram 3.3.2 FeldPangram 4-FeldStatus
windows[].labelwindows[].labelWerte geändert
windows[].Vertrauenswürdigkeitwindows[].VertrauenswürdigkeitBleibt vertraut
windows[].ai_assistance_scorewindows[].ai_assistance_scoreBleibt vertraut
—windows[].is_humanizedNeu
—windows[].humanizer_scoreNeu
—VersionRücksendungen "4.0"

Das größte Kompatibilitätsproblem ist windows[].label. Die beiden bisherigen KI-gestützten Kategorien wurden zu einer einzigen zusammengefasst KI-gestützt Bezeichnung.

Änderungen bei der Rechnungsstellung

Noch ein letzter Hinweis: Wir ändern die Art und Weise, wie wir unsere API abrechnen.

Wir verbessern die Detailgenauigkeit unseres Nutzungszählers. Anfragen werden nun pro 100 Wörter statt pro 1.000 Wörter abgerechnet. Dies wird für viele von Ihnen von Vorteil sein.

Aber eine kleine Vorwarnung: Pangram 4 ist ein größeres und leistungsfähigeres Modell, weshalb wir den Preis entsprechend anpassen mussten.

Die aktuellen Preisinformationen finden Sie auf der Preisseite!

Bevor Sie den gesamten Produktionsdatenverkehr auf Pangram 4 umstellen, sollten Sie das aktualisierte Abrechnungsmodell im Hinblick auf die typische Anfragelänge und das typische Anfragevolumen Ihrer Anwendung überprüfen.

Empfohlener Migrationsprozess

1. Aktualisieren Sie Ihren Client

Nutzer der REST-API können den bestehenden Aufgaben-Endpunkt weiterhin verwenden.

Benutzer des Python-SDK sollten die Version installieren 1.0.0:

pip install --upgrade pangram-sdk==1.0.0

2. Pangram 4 ausdrücklich anfordern

Fügen Sie den Modellparameter jeder Anfrage hinzu:

{
  "model": "pangram-4"
}

3. Aktualisierung der exakten Etikettenvergleiche

Prüfungen ersetzen für:

Leicht KI-gestützt
Mäßig KI-gestützt

Mit:

KI-gestützt

Stellen Sie außerdem sicher, dass Ihre Integration genau die folgenden vier Pangram-Bezeichnungen unterstützt:

Von KI generiert
KI-unterstützt
Von Menschen verfasst

4. Unterstützung der neuen Fachbereiche

Aktualisieren Sie Antworttypen, Validierungsschemata, Datenbankmodelle und Analyse-Pipelines, um Folgendes zu unterstützen:

windows[].is_humanized
windows[].humanizer_score
version

Die neuen Fensterfelder können zunächst als optional behandelt werden, wenn Ihre Anwendung noch keine Humanisierungsanalyse nutzt.

5. Überprüfung der Abrechnungsannahmen

Anfragen werden nun pro 100 Wörter statt pro 1.000 Wörter abgerechnet.

Testen Sie die Wirkung anhand repräsentativen Produktionsdatenverkehrs.

Checkliste für die Migration

  • Aktualisieren Sie das Python-SDK auf pangram-sdk==1.0.0, falls zutreffend
  • Hinzufügen Modell: „pangram-4“ für API-Anfragen
  • Abhängigkeiten von Leicht KI-gestützt
  • Abhängigkeiten von In moderatem Umfang KI-gestützt
  • Support KI-gestützt
  • Unterstützung für hinzufügen windows[].is_humanized
  • Unterstützung für hinzufügen windows[].humanizer_score
  • Vergewissern Sie sich, dass die Antwortversion "4.0"
  • Sehen Sie sich den neuen Abrechnungszähler pro 100 Wörter an
  • Testen Sie die Migration vor dem 30. September 2026

Fragen?

Wir freuen uns darauf, dass ihr alle Pangram 4 nutzt. Meldet euch gerne, falls ihr Probleme habt. Wir werden in den kommenden Tagen besonders schnell reagieren!

Für Unterstützung bei der Migration wenden Sie sich bitte an support@pangram.com.
