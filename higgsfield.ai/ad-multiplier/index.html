Still have questions?

We’ve answered the most frequently asked questions

What is Ad Multiplier?
A Higgsfield skill that multiplies one video into many variants. The video stays the same as the original — only the details change: the character, the clothing, the location, or the objects in frame. It's distributed through the Higgsfield MCP server and Supercomputer (Mr. Higgs).
What exactly can it change?
Characters, clothes, locations, and objects. You can ask for one swap or all of them per variant — the performance, cut, and pacing of the original are preserved.
What happens to the audio?
After multiplying, all generated videos keep the original audio — the voice, music, and timing carry over to every variant.
What about captions?
Captions can be removed from the original video, so variants ship clean. As an additional step, you can generate new captions in a different language.
Can it translate my ad?
Yes, as an additional step you request explicitly. It changes the language and generates new captions in the target language. Keep in mind the translated voice is synthetic — the original-audio guarantee applies to non-translated variants.
Where does it run?
In Claude, through the Higgsfield MCP server — MCP (Model Context Protocol) is an open standard that lets AI agents use external tools, so any MCP-compatible client works too. The same skill is also available in Supercomputer (Mr. Higgs) on Higgsfield.
Do I need an API key?
No. Add the connector URL in Claude's settings and sign in with your Higgsfield account. There are no keys to manage.
How does pricing work?
Generations use the same credit system as the Higgsfield platform. Each variant shows its credit cost based on model and resolution, and your existing plan credits work through any connected agent.
Can I use the results commercially?
Yes — variants you generate are yours to publish across organic and paid channels, subject to Higgsfield's Terms of Use.
