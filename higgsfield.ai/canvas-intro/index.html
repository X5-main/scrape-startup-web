Still have questions?

We’ve answered the most frequently asked questions

What is Canvas, and how is it different from the rest of Higgsfield?
Canvas is a node-based workspace where prompts, references, and generations from any Higgsfield model live on a single infinite board. Instead of running each generation in isolation, you connect nodes — a prompt feeds an image, an image feeds a video, a style branches into variations — so a whole campaign or scene becomes one continuous pipeline rather than a folder of disconnected outputs.
Which models can I use inside Canvas?
All of them. Soul 2.0, Seedance 2.0, Kling 3.0, Wan 2.7, Veo 3.1, Nano Banana Pro, GPT Image 2.0 — every model on Higgsfield runs inside the graph, and you can route outputs from one into another. Generate a character in Soul, animate it in Kling, upscale through another node — all in one canvas.
How does real-time collaboration work?
Share a canvas link and your team joins live, the same way they would in Figma. Multiple people can drop nodes, chain pipelines, and generate at the same time. Every version is saved automatically, and comments stay attached to the specific nodes they reference instead of getting lost in a Slack thread.
Can I save a workflow and reuse it?
Yes. Any canvas can be saved as a reusable template — for ad variants, character sheets, storyboards, or any pipeline you run repeatedly. Duplicate, swap the inputs, and you have a new campaign in minutes instead of rebuilding from scratch.
How are credits charged on Canvas?
You pay only for the models you actually run. Building the graph, connecting nodes, and editing prompts is free — credits are deducted when a node generates an image or video, at the same rate as that model elsewhere on Higgsfield.
Can I bring Soul ID characters and my own assets into Canvas?
Yes. Soul ID characters, uploaded products, brand references, and any of your previous generations all drop in as nodes. That means consistent characters across an entire campaign and on-brand visuals without re-uploading the same reference into every shot.
