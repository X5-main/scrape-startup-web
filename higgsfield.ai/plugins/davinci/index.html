We’ve answered the most frequently asked questions

What makes Higgsfield Plugins for Resolve different from other AI tools?
Seven AI tools run natively inside DaVinci Resolve — no exports, no switching apps, no manual file handoffs. Generate video and images, reframe to any aspect, remove backgrounds, upscale to 8K, and edit with natural language, all from one panel in your Resolve workspace.
Which versions of DaVinci Resolve are supported?
DaVinci Resolve 19 and newer on both macOS and Windows. Older versions are not supported — update via Blackmagic's site if needed.
How do I install the plugins?
Download the installer for your OS (.dmg for macOS, .exe for Windows). Run it — the installer detects DaVinci Resolve automatically and adds Higgsfield to your Workspace menu. No helper apps, no ZXP tools, no manual file copying.
Where does the panel appear inside Resolve?
Under Workspace → Scripts → Higgsfield in the menu bar. The panel can be docked anywhere in your Resolve workspace, just like any native tool.
Do I need an internet connection?
Yes. Higgsfield Plugins run AI inference on our servers, so an active internet connection is required while generating. Results are sent back into your Resolve media pool automatically.
Which plugins are included?
One installer ships all seven plugins: Reframe, Remove Background, Upscale, Draw to edit, Edit Video, Generate Video, and Generate Image. All seven live in the same panel — switch between them with one click.
Can I use the plugins for commercial projects?
Yes. Generations made through Higgsfield Plugins are covered for commercial use on paid plans. Full terms are in the Higgsfield Terms of Service.
