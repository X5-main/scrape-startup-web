INTEGRATIONS

One connection. Every tool your agents need.

Your agent connects to Fabriq once. Every integration your organization has authorized becomes reachable — each person acting on their own accounts, every call checked and recorded.

Don’t see it? Bring it.

Anything you add lands on the same hub, with the same permissions, the same credential handling, and the same audit trail as everything built in.

Any OpenAPI service

Point Fabriq at an OpenAPI spec and every endpoint becomes a governed tool, with the same permissions and audit trail as a built-in connector.

Any MCP server

Register an MCP server and its tools join the same hub — your agents reach them through one endpoint instead of a second integration path.

Your own database

Expose a Postgres database as read-only tools, so an agent can answer from your data without a connection string of its own.

Systems with no public address

A private network connector opens an outbound-only tunnel, so internal services stay unreachable from the internet and still reachable by your agents.
