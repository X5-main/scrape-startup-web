Every model through one gateway. Claude, GPT, DeepSeek, Gemini, and whatever runs on your own machines, all behind one account. You set up keys and billing once.

The cheapest model that can do the job. The router tries local models first, then cheap cloud, and only pays frontier rates when a task needs them. In practice about 80% of tokens never leave your hardware, so they cost nothing.

Set the rules once. An admin decides which providers are allowed, what has to stay local, and how much each team can spend. The policy installs as a signed profile on every machine.

One bill. The org buys credits once and everyone draws from the same pool. Finance gets one invoice that shows what each team spent.
