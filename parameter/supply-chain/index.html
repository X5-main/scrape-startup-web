[ why parameter ]

The graph.
Not the guesswork

Most tools dump every advisory in your tree and call it coverage. Parameter raises only what an attacker can reach, and ships the fix with it.

Reachability, not a CVE dump

Parameter traces whether your code can actually reach the vulnerable path. The queue stays short, and every entry is real.

Malware caught at install time

Install scripts, obfuscated payloads, and typosquats are inspected before they run in CI. The attacks signature databases miss until it’s too late.

An SBOM that never goes stale

A signed CycloneDX and SPDX inventory regenerates on every push, so what you attest always matches what you shipped.
