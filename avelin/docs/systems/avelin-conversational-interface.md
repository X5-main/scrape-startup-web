# AVELIN-GPT

## 1) What This System Is

**AVELIN-GPT** is the private, self-hosted conversational workspace of the AVELIN AI Intelligence Platform — the **Enterprise Platform** pillar where users interact with Cross-Model MoE technology.

It is the business interaction layer where users:

- ask questions and run structured analysis
- interact with files, media, and external intelligence
- activate specialist assistants and tools
- execute real business actions through connected systems
- access 9 specialist model families with AA Index scores up to 67 (agentic) and context windows up to 1M tokens

## 2) Who Uses It

- Business users across sales, support, operations, finance, legal, and leadership
- Team managers coordinating cross-functional workflows
- Executive assistants and coordinators handling planning and communication
- Platform admins governing access, usage, and policy controls

## 3) Business Problems It Solves

- Tool sprawl and context switching across disconnected AI products
- Slow decision cycles caused by separated analysis and execution systems
- Limited trust in public AI interfaces for sensitive business work
- Inconsistent governance and weak visibility over usage and spend

## 4) Full AVELIN-GPT Feature Catalog

The catalog below reflects the current AVELIN-GPT capability set.

### A) Core Conversation and Workflow Experience

- Chat-first workspace for daily business execution
- Create, rename, duplicate, archive, unarchive, and delete conversations
- Automatic conversation title generation
- Edit, resubmit, and continue messages without restarting the session
- Advanced conversation forking and branching for context control
- Sort and organize conversation lists for faster navigation
- Conversation tags for topic and workflow grouping
- Global search across conversations and messages
- Stream abort controls for in-flight responses
- Resumable streams after connection interruptions
- Multi-tab and multi-device conversation continuity
- Import existing conversation history from other supported chat tools
- Export conversations as screenshot, markdown, text, and JSON

### B) Model Access and Endpoint Flexibility

- Access to 9 specialist model families through AVELIN Cross-Model MoE orchestration
- Intelligence family (ultra/pro/fast/plus), Coding family (coding/coding-plus/coding-architect), Agentic family (agentic/agentic-high/agentic-fast)
- AA Index quality scores visible for model selection (ranging from 38 to 67)
- Switch model endpoint and response profile mid-conversation
- Unified API-compatible endpoint model for approved providers
- Support for private/local model endpoints in sovereign deployments
- User-scoped API key management for allowed endpoint usage
- Endpoint and model catalog configuration
- Category-based organization of model options
- Support for advanced response pipelines for reasoning-focused models
- Self-improving platform: new models integrated within 48 hours of release

### C) Reasoning and Response Controls

- **Classic Mode** for direct, fast output
- **Memory Mode** for persistent context continuity
- **Debate Mode** for multi-perspective reasoning and conflict analysis
- Dynamic reasoning interface for supported reasoning-capable models
- Show/hide reasoning panel controls for user preference
- Reasoning effort and thinking-budget controls where supported
- Per-session generation controls (temperature, top-p, and related response tuning)

### D) Multimodal, Media, and Voice

- Text, image, file, and voice interactions in one continuous workflow
- Image upload and image analysis in chat context
- Text-to-image and image-to-image generation/editing
- Support for image workflows through built-in and tool-connected engines
- Generative UI code artifacts (React, HTML, and Mermaid outputs)
- Artifact style modes for default, UI-framework, and custom output patterns
- Speech-to-text for hands-free input
- Text-to-speech for spoken responses
- Automatic audio send/play workflows
- Audio transcription support
- Voice response caching for repeated playback efficiency
- Upload and manage profile/assistant/agent avatars

### E) Files, Knowledge, and Context Management

- File upload for contextualized chat and analysis
- File search across uploaded material
- Chat-with-files workflows across supported model endpoints
- Attach documents to assistant/agent knowledge scopes
- Context continuity across message edits, branches, and resumptions
- Persistent user memory with configurable memory preferences
- Memory controls (enable/disable) based on user or policy profile
- Token-aware context behavior to keep long sessions usable

### F) Agents, Tools, and Action Execution

- No-code specialist assistant creation for role-focused workflows
- Assistant marketplace discovery and activation
- Assistant sharing with specific users or groups
- Tool-enabled assistants for search, execution, and retrieval tasks
- Full Model Context Protocol (MCP) integration for tool access
- MCP server lifecycle controls (create, update, remove, connect)
- MCP OAuth connection flow support
- MCP tool discovery and invocation in active workflows
- MCP connection status visibility
- MCP variable/configuration management
- OAuth-enabled custom actions for business system operations
- Assistant-style orchestration flows for tool-based tasks
- Assistant API-style orchestration support for enterprise assistant workflows
- Sandboxed code execution environments for analytical workflows
- Multi-language runtime support (Python, JavaScript/TypeScript, Go, C/C++, Java, PHP, Rust, Fortran)
- File upload, processing, and download in execution workflows

### G) Web and External Intelligence

- Built-in web search workflows for live external context
- Pluggable search provider support
- Pluggable scraping/content retrieval support
- Pluggable reranking support for better relevance
- Configurable reranking endpoint behavior
- Evidence-first context assembly for stronger answer grounding

### H) Personalization and Productivity

- Create, save, and share reusable conversation presets
- Switch presets mid-chat for faster workflow adaptation
- Prompt library with create/save/share controls
- Prompt groups for better prompt organization
- Production tags for approved, reusable prompts
- Favorite models and endpoints for quick access
- Customizable interface behavior for novice and power users
- Multilingual interface for global teams
- Personal memory-driven interaction continuity

### I) Collaboration and Sharing

- Shared conversation links with public/private access controls
- Shared link lifecycle controls (create, update, revoke, delete)
- Prompt sharing across users and groups
- Assistant sharing across users and groups
- User/group selection workflows for controlled collaboration
- Team-safe collaboration with policy-defined permission boundaries

### J) Security, Governance, and Administration

- Multi-user authentication with OAuth2, LDAP, and email/password options
- Two-factor authentication with verification and backup codes
- User lifecycle controls (invite, activate, suspend, ban, remove)
- Role-based access control for platform governance
- Granular permission system for prompts, assistants, memory, MCP, and marketplace
- Moderation controls for safer content handling
- Token usage and spend visibility
- User balance and quota administration
- IP- and user-level rate limiting controls
- Terms acceptance and account verification controls
- Ban management and enforcement tooling
- Admin announcement/banner capability for platform notices

### K) Deployment and Operational Capabilities

- Containerized deployment options for predictable operations
- Configuration-driven setup using environment and YAML controls
- Reverse-proxy compatible deployment patterns
- Local/private and cloud deployment flexibility
- Horizontal-scale readiness for high-volume usage
- Persistent conversation/state backends
- Search index integration for fast discovery workflows
- Optional tracing/observability integration points
- Kubernetes deployment options for enterprise operations

### L) Conditional Capability Notes

- Some advanced controls depend on deployment profile, policy settings, and enabled integrations.
- Marketplace, extended governance, and certain tool categories can be restricted or expanded by administrator policy.

## 6) Typical Business Scenarios

### Scenario: Executive Decision Sprint

- Trigger: urgent strategic decision with incomplete internal and external context
- Workflow: use Debate Mode, web intelligence, and specialist assistants to compare options and risks
- Outcome: faster board-ready decision packets with clearer trade-offs

### Scenario: Operations Coordination Hub

- Trigger: cross-functional execution with many stakeholders and moving dependencies
- Workflow: coordinate in one conversation workspace, share prompts/assistants, and trigger connected actions
- Outcome: less coordination friction and stronger execution follow-through

### Scenario: Knowledge-Driven Service Resolution

- Trigger: complex customer issue requiring internal docs plus external validation
- Workflow: chat with files, use memory continuity, and run tool-assisted actions
- Outcome: faster, more accurate case resolution with traceable context

### Scenario: Daily Productivity Automation

- Trigger: high-volume planning, communication, and administrative tasks
- Workflow: use reusable presets, voice interaction, shared prompts, and assistant support
- Outcome: lower cognitive overhead and better daily consistency
