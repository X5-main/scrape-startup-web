Monitoring, analytics, and optimization tools for AVELIN API usage.

## Available Tools

### [Helicone](helicone.md)
Observability and evaluation platform to supercharge inference. Monitor costs, latency, and model performance with your API key.

### [analystOS](analyst-os.md)
Web UI for AI-powered research with optional Notion automation. Features RAG, URL scraping, and 50+ model support.

### [Cloudflare AI Gateway](cloudflare-ai-gateway.md)
Tools to monitor, control, and optimize your AI applications with caching, rate limiting, and analytics.

### [Maxim AI](maxim-ai.md)
Agent simulation, evaluation, and observability platform for deploying agents with quality and speed.

### [PostHog](posthog.md)
Developer tools designed to help product engineers build successful products with AI-powered analytics.

## What to Monitor

| Metric | Why it matters |
|---|---|
| **Cost per request** | Track spending across models and identify optimization opportunities |
| **Latency (TTFT, total)** | Measure time-to-first-token and total response time |
| **Token usage** | Monitor input/output tokens to optimize prompts |
| **Error rates** | Track API failures and provider issues |
| **Model performance** | Compare quality across different AVELIN models |
