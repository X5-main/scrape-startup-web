## Additional Automation Tools

### [NanoClaw](../nanoclaw.md)
Lightweight alternative to OpenClaw running agents in isolated containers.

### [Agent Zero](agent-zero.md)
A platform to build autonomous AI agents effortlessly, with support for multi-step reasoning and tool use.

### [AiAssistWorks](aiassistworks.md)
AI for Google Sheets, Slides & Docs. Process 100k+ rows with text commands and create charts/pivot tables.

### [Ottex](ottex.md)
Voice dictation shortcuts (WisprFlow + Raycast style) with BYOK. Auto-formats dictated emails, Slack messages, and prompts.

### [PostQode](postqode.md)
AI-powered SDLC platform with specialized agents for API, Web, and Mobile testing, plus a generic development agent.

### [Quests](quests.md)
The open-source app builder for rapid prototyping and development.

### [Space Agent](space-agent.md)
Free, open-source AI agent that builds your workspace directly in the browser.

### [Stirrup](stirrup.md)
Lightweight framework for building agents using ChatCompletionsClient and your own API key.
