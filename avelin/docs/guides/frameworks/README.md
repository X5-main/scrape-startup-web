## Additional Frameworks

### [Mastra](mastra.md)
Open-source TypeScript framework for building AI-powered apps and agents with first-class support for tool use and structured output.

### [openrouter-rs](openrouter-rs.md)
Community-maintained Rust SDK and companion CLI for OpenRouter-compatible APIs like AVELIN.

### [OpenRouter MCP](openrouter-mcp.md)
All-in-one MCP server that gives Claude Desktop, Cursor, Kiro, VS Code, Windsurf, and Cline access to OpenRouter's 300+ LLMs — chat, image/audio/video analysis, and generation.
