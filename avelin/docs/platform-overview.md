# Platform Overview

## The Sovereign AI Laboratory

AVELIN is an **AI Laboratory** that builds frontier-class intelligence. We train and fuse models into specialist families — then deploy them inside your perimeter, on your GPUs, at half the cost of closed frontier providers.

We are not a chatbot wrapper, a token reseller, or a pass-through API gateway. AVELIN builds **Cross-Model MoE** — a trained Mixture-of-Experts meta-model architecture with difficulty-based cascading that synthesizes intelligence from the world's most capable open models. This is not routing. This is trained AI technology that produces outputs exceeding any single model on its own.

The result: intelligence that matches or exceeds frontier providers on independent benchmarks, at up to 85% lower cost, with the sovereignty and compliance controls that regulated enterprises require.

## Three Pillars

AVELIN operates across three integrated pillars:

### Pillar 1: AI Laboratory (Primary)

Like Mistral, we are fundamentally a research and engineering laboratory that builds AI models. Our core technology is **Cross-Model MoE** — a trained Mixture-of-Experts meta-model with difficulty-based cascading that fuses open models into **9 specialist model families**, each optimized for a distinct workload class:

- **Intelligence** — general reasoning, analysis, and complex problem-solving
- **Coding** — software engineering, architecture, and code generation
- **Agentic** — autonomous multi-step task execution and tool use

Each family contains multiple tiers (e.g., ultra, pro, fast) so enterprises can match intelligence level to task complexity — and never overpay for capability they don't need.

**We build and fuse models, we don't just route them.** Cross-Model MoE is a trained meta-model — with learned gating, specialist weighting, and difficulty-based cascading — that produces synthesized intelligence. New open-source models are evaluated and integrated within 48 hours, continuously improving the system without the $100M+ training budgets of closed providers.

### Pillar 2: Cloud Token Factory

Like Cohere, we operate an API-first serving infrastructure that delivers AVELIN's specialist models at scale — **up to 85% cheaper than frontier alternatives**.

- Drop-in compatible API (OpenAI-compatible endpoint)

- Real-time usage metering and spend controls

### Pillar 3: Enterprise Platform

Like Palantir, we deploy sovereign intelligence directly inside our customers' infrastructure. This is our **primary business model** — enterprises license AVELIN for deployment on their own hardware.

- **Sovereign GPU licensing** — deploy AVELIN on your own GPUs ($8K–$18K per GPU/year)

- **Role-based access governance** — policy controls enforced at every layer

## Cross-Model MoE: Trained Intelligence, Not Routing

Cross-Model MoE is the core technology that differentiates AVELIN from API aggregators and pass-through gateways.

| Aspect | API Aggregator / Gateway | AVELIN Cross-Model MoE |
|--------|--------------------------|------------------------|
| Architecture | Request forwarding | Trained MoE meta-model |
| Intelligence | None — passes through to providers | Synthesized — models fused with learned gating |
| Output quality | Limited to single model | Exceeds any individual model |
| Improvement | Dependent on upstream changes | Self-improving within 48 hours |
| Deployment | Cloud-only, data leaves perimeter | Sovereign — runs on your GPUs |
| Cost structure | Markup on provider pricing | Structurally cheaper architecture |

Cross-Model MoE uses **difficulty-based cascading**: each request is analyzed for complexity and routed through trained specialist layers. Simple queries use efficient pathways. Complex reasoning activates deeper expert fusion. The meta-model learns which specialists to weight for each task class — this is synthesis, not a gateway.
