# List Vault Entries

> GET /v1/users/:user_id/vault — list (masked, expired excluded).

<RequestExample>
  ```bash theme={"theme":"css-variables"}
  curl https://api.usenaive.ai/v1/users/USER_ID/vault \
    -H "Authorization: Bearer $NAIVE_API_KEY"
  ```
</RequestExample>

Values are masked. Use the reveal endpoint to read a value.
